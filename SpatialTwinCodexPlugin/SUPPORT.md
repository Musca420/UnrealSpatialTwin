# Reporting a problem

Include plugin version, OS, exact Unreal build, Python/MCP versions, failing
command or tool, expected result, actual status and revision, and a small
reproduction in an independent project. Distinguish editor, PIE and saved
state. Attach filtered error lines and the relevant receipt, not the whole
project, personal saves, credentials or complete logs.

For a write timeout, preserve the journal and inspect native/canonical effects
before continuing. Do not repeat the operation merely to obtain a response.

The publication draft has no invented support URL or publisher identity.
The repository chosen for publication should enable issues and provide its
actual contact details before any directory submission.
