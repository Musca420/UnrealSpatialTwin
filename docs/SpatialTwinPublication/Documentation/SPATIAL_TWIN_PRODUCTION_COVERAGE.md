## Supported workflow

Project-neutral persistent SQLite Canonical, stable source identities/history,
explicit initial scan including saved unloaded World Partition descriptors,
incremental editor events and saved-source reconciliation; indexed scene,
asset/dependency, collision geometry/raycast/support and regional navigation
queries. Offline Shadow supports scoped actor/component/asset changes,
staged Blender source, placement and grounding with strict validation. Official
Unreal MCP remains the sole live action authority; journals guard once-only
execution, scoped saves and known-effect recovery. Sync/readback and native
renders verify delivery. Focused Codex entrypoints expose exact contracts.

Jev is optional. Deterministic queries, planning and validation work without a
model API. No game-specific assets/maps/paths belong to the product runtime.
No Computer Use or full scan at each task. Unit/input contract tests cover
completeness, stale revisions, unknown data and unsafe mutations.

## Explicit boundaries

These proofs cover the tested native cases, agents, regions and source states.
They do not certify every World Partition container/nav input/Blueprint,
other engine versions/platforms, an entire campaign, or broad artistic quality.
Ambiguous cold moved ISM can acquire new IDs. Uncertain native effects before a
terminal journal, unsupported custom input, stale/missing geometry/navigation
remain UNKNOWN or refused. Never erase these limits, disable guards or replay
an uncertain write to obtain a PASS. Native bounds and finite support rays
alone cannot certify exact contact.

The complete package report distinguishes functional qualification from speed:
the wide matrix does not imply the portfolio percentage for every function.
Setup/build/first scan/cache/failures/development are separately preserved.
No exact account billing, reviewer cost, total ROI or universal40/50claim.
